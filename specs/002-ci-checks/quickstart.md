# Quickstart: CI Checks

To run the same checks locally that the CI pipeline will run, use the following commands from the repository root:

## 1. Install Dependencies
```bash
npm install
```

## 2. Run Linter
```bash
npm run lint
```
This will check for code style and formatting issues.

## 3. Run Type Checker
```bash
npm run typecheck
```
This will verify TypeScript types across the project.

## 4. Run Tests
```bash
npm test
```
This will run the unit test suite.
